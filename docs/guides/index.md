# Guides

Task-oriented documentation, grouped by what you're integrating. Every
group below is a section in the left nav with its own set of pages.

- **Web GUI** - Browser-based operator dashboard: install, screens, playground. [Web GUI](../gui/index.md).
- **Adapters** - Wire in Claude Code, Codex, Gemini CLI, and 40+ other CLI agents. [Adapters](../adapters/index.md).
- **Sandboxes** - Pluggable isolation backends: Daytona, Blaxel, Runloop, Vercel. [Sandbox overview](../architecture/sandbox.md).
- **Editors and host registration** - Register Bernstein into Claude Code, Cursor, Continue, Cline, Zed, Aider. [Claude Code](../substrate/claude-code.md).
- **Issue trackers** - Linear, Jira, Asana, ClickUp, GitHub Projects, Plane, ServiceNow. [Tracker contract](../trackers/contract.md).
- **Git hosting and CI** - GitHub Action, GitHub App, and GitLab App setup. [GitHub Action](../integrations/github-action.md).
- **MCP** - Bernstein's own MCP server and client, plus tool-search lazy loading. [MCP server](../mcp/server.md).
- **Hooks, plugins and skills** - Lifecycle hooks, the plugin SDK, and progressive skill packs. [Hook system](../integrations/hook-system.md).
- **Memory and context** - Session memory, cross-task sharing, and context compaction. [Session memory](../memory/session-memory.md).
- **Cloud (Cloudflare)** - Run agents on Cloudflare's edge: Workers, R2, D1, Vectorize. [Cloudflare overview](../cloudflare/cloudflare-overview.md).
- **Everyday workflows** - Recipes, worktrees, snapshot undo, and session handoff. [Recipes](../operations/recipes.md).
